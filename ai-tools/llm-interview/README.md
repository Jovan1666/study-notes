# 大模型面试专题：八股与检索

> 秋招准备期间整理的 LLM 面试知识笔记 —— 不只记结论，重点是**把每个技术点"为什么这么做"讲清楚**。

这个专题来自我准备大模型岗位秋招时的一份笔记，覆盖 RAG 全链路（解析清洗 → 切块 → 入库 → 召回 → 去重 → 重排 → 生成）、向量检索原理，以及四种进阶 RAG 形态。

写作上刻意避开"术语堆砌"——每个概念都先讲它**要解决什么问题**，再给机制和参数，最后才是面试答法。
